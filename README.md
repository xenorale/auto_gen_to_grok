# Auto Grok Studio 🎬

Автоматизированный инструмент для массовой генерации изображений и видео через нейросеть Grok (xAI) с удобным графическим интерфейсом.

## ✨ Основные возможности

*   **Интерактивная галерея**: Просматривайте сгенерированные результаты в реальном времени прямо в приложении.
*   **Полный контроль**: Кнопки «Сохранить» и «Перегенерировать» на каждой карточке превью позволяют управлять процессом без переключения в браузер.
*   **Массовая обработка**: Автоматическое переключение вкладок для генерации персонажей и сцен из CSV-файлов.
*   **Умный пропуск**: Бот автоматически пропускает уже созданные файлы, экономя ваше время и лимиты.
*   **Поддержка форматов**: Генерация в форматах 9:16 (Shorts/Reels) и 16:9 (YouTube).
*   **Стелс-режим**: Интеграция Playwright Stealth для минимизации вероятности блокировок.

## 🚀 Быстрый старт

1.  **Настройка среды**:
    *   Установите Python 3.10+.
    *   Установите зависимости: `pip install playwright playwright-stealth flet`.
    *   Установите браузер: `playwright install chromium`.

2.  **Подготовка данных**:
    *   Заполните `characters.csv` для генерации персонажей.
    *   Заполните `scenes.csv` для генерации сцен и видео.
    *   *(Примеры файлов доступны в репозитории)*.

3.  **Запуск**:
    *   Запустите `gui.py` или используйте `Run Studio.bat`.
    *   Укажите путь к папке проекта.
    *   Нажмите **Launch Session**.

4.  **Работа с галереей**:
    *   Как только Grok выдаст результат, он появится в верхней панели.
    *   Нажмите 💾 (зеленая кнопка) для сохранения.
    *   Нажмите ♻️ (оранжевая кнопка), если хотите переделать кадр.

## 🛠 Технологии

*   **Playwright**: Автоматизация браузера.
*   **Flet (Flutter)**: Современный GUI на Python с эффектом Glassmorphism.
*   **Python**: Основная логика бота.

## ⚠️ Важно

Для работы бота необходимо, чтобы основной браузер Chrome был закрыт (так как используется отладочный порт 9222), либо бот сам попытается запустить его в режиме отладки.
